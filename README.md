# 📊 STRATZ Dota 2 Telegram Bot

Асинхронный Telegram-бот для быстрого получения и анализа игровой статистики Dota 2 в реальном времени. Проект разработан на базе современного фреймворка `aiogram 3.x` и взаимодействует с платформой STRATZ через высокопроизводительное **GraphQL API**.

Бот создан как удобная, легковесная альтернатива тяжелым веб-сайтам (Stratz, Dotabuff). Позволяет игрокам и их друзьям моментально проверять свои результаты прямо со смартфона, не открывая браузер и не сворачивая игру.

## 🚀 Ключевой функционал & Фичи

* **Парсинг GraphQL API**: Быстрое получение данных напрямую со STRATZ без загрузки лишнего HTML-кода.
* **Асинхронная архитектура (`httpx`)**: Бот обрабатывает запросы конкурентно, обеспечивая моментальный отклик интерфейса даже при одновременном использовании несколькими пользователями.
* **Разделение топиков (Inline UI)**: Удобная навигация по категориям (Последние матчи, Ранг, Винрейт, Топ-5 недавних героев) в один клик без перезапуска диалога.
* **Fault Tolerance (Отказоустойчивость)**: Реализована обработка сетевых ошибок (сетевые таймауты, ошибки 5xx, флуд-контроль Telegram) и специфичных сбоев GraphQL.
* **Автономный Деплой**: Проект подготовлен для работы на серверах Linux.

## 🛠 Стек технологий

* **Language:** Python 3.11+
* **Framework:** Aiogram 3.x (Asyncio)
* **API Client:** HTTPX (Asynchronous HTTP client)
* **Query Language:** GraphQL
* **Data Processing:** BeautifulSoup4 & ElementTree (для работы со Steam Web XML)
* **Environment:** Python-dotenv, Linux/Bash (Process Management)

## 📁 Архитектурная структура (MVP)

Проект спроектирован по модульному принципу, что позволяет легко масштабировать его функционал:
* `main.py` — Инициализация бота, конфигурация сессий и запуск асинхронного поллинга.
* `parser.py` — Изолированный сервисный слой для формирования GraphQL-запросов и безопасного взаимодействия с API STRATZ.
* `parser_server.py` — Тот же parser.py, но нужен при блокировке вашего IP от Cloudflare.
* `steam_id.py` — Модуль валидации пользовательского ввода и конвертации профилей/ссылок в `steamID64`.
* `formatters.py` — Уровень бизнес-логики, отвечающий за парсинг JSON-структур, сортировку данных и генерацию красивой HTML-разметки для Telegram.
* `constants.py` — Статические словари данных (ID героев, названия рангов Dota 2).

## ⚙️ Инструкция по локальному запуску

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/MoFeed63/stratz-telegram-bot
   cd stratz-telegram-bot
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Создайте файл конфигурации `.env` в корневой папке:**
   ```env
   BOT_TOKEN=ваш_токен_телеграм_бота
   API_TOKEN=ваш_токен_stratz_api
   PROXY_URL=ваш_прокси_если_необходимо (опционально)
   ```

4. **Запустите бота:**
   ```bash
   python main.py
   ```
